```markdown

**Explanation**:
[Minimum 50 words explaining why the correct answer is right,
```

## Quality Checklist (Before Submission)

### Question Stem
- [ ] Positive phrasing (no "NOT", "EXCEPT")
- [ ] Single concept tested per question
- [ ] Clear and unambiguous
- [ ] Minimum 20 characters

### Options
- [ ] Exactly 4 options (A-D)
- [ ] Grammatically parallel
- [ ] No "All/None of the above"
- [ ] No absolute terms unless factually accurate

### Explanations
- [ ] Correct answer explanation ≥50 words
- [ ] All 3 incorrect options explained
- [ ] Educational value in explanations

### References
- [ ] Source citation present
- [ ] Citation format correct
- [ ] Related section specified
